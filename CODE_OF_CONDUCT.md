# Code of conduct

GH Random welcomes people regardless of background, identity or experience.
This applies to issues, PRs, reviews and other project spaces, including when
representing the project elsewhere.

Be considerate and specific. Critique ideas/code, not people. Ask questions,
accept constructive feedback, acknowledge mistakes and respect people's time
and right to disengage. Disagreement is welcome; harassment, discrimination,
threats, unwanted sexual attention, personal attacks, doxxing, spam and
retaliation are not.

Maintainers may remove inappropriate content, request changed behavior, limit
participation or block repeated/serious misconduct. Responses should reflect
severity/context, prioritize safety and avoid exposing private information.
Good-faith mistakes normally deserve an explanation and chance to improve;
severe abuse can require immediate action.

For public project behavior, ask a maintainer to review the thread without
repeating private or abusive details. For private abuse/safety concerns, use
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
to contact GitHub Support; repository-admin reporting exists only where GitHub
offers it. Do not use a vulnerability advisory for a conduct complaint. Security
flaws belong in [SECURITY.md](SECURITY.md)'s private channel. Maintainers consider
moderation feedback but cannot promise confidential handling in a public issue.
